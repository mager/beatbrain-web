# Humans Implementation Plan

**Goal:** Build a private member showcase with music, search, and filters.
**Architecture:** Share a bounded Prisma directory query between server rendering and a member-only API. Keep controls in one page and use a CSS module for the surface.
**Stack:** Existing Next.js Pages Router, React, Prisma, and Heroicons.
**Spec:** `.impeccable/surfaces/humans.md`.

## Constraints

Preserve existing local changes, members, and private access. No migrations or dependencies. Return only profile and posted music data. Following uses the signed-in actor. Keep global design files unchanged.

## Review focus

Stale requests must not replace newer results. Controls must remain usable during a failed request. No private emails or credentials may reach directory responses. Members without posts or images must remain visible. The extra navigation item must fit narrow screens.
