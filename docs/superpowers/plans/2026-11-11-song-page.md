# Song Page Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Show instruments near the song title and make credits easier to scan.
**Architecture:** Reuse TrackHero and the original icon assets. Add a pure credit grouping helper and a small instrument component. Scope new layout styles to the song page.
**Tech Stack:** Next.js, React, TypeScript, existing CSS and PNG assets.
**Spec:** docs/superpowers/specs/2026-11-11-song-page-design.md

## Global Constraints

- Preserve existing local changes, access checks, source data, and creator links.
- No invented credits, identity aliases, new dependencies, or deployment.

## Review Focus

- Same names with different IDs must remain separate.
- Legacy name-only credits must not be assigned a guessed creator link.
- Unknown icons must keep readable role labels.
- Long names and many instruments must wrap on phones.
- Empty credits and unavailable artwork must preserve usable actions.
